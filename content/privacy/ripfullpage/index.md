# Privacy Policy for ripfullpage

Effective Date: June 12, 2026

ripfullpage is a Chrome extension for capturing, cropping, and saving webpage screenshots.

## Data Collection

ripfullpage does not collect, store, sell, rent, or share any personal information.

## Screenshot Processing

All screenshot capture, cropping, and image processing are performed locally in the user's browser.

ripfullpage does not upload screenshots, webpage content, browsing history, or any other user data to external servers.

## Permissions

ripfullpage may request browser permissions such as `activeTab`, `scripting`, `storage`, and `downloads`.

These permissions are used only to:

- Capture the current webpage
- Process screenshots locally in the browser
- Save screenshots to the user's device
- Store extension preferences locally

## Third-party Services

ripfullpage does not use third-party analytics, advertising SDKs, tracking services, or remote code.

## Data Security

Since ripfullpage does not collect or transmit user data, no personal data is stored on external servers.

## Changes to This Policy

This privacy policy may be updated from time to time. Any changes will be posted on this page.
